# Pipeline Engineering Academy

Interactive lessons, calculators and standards guidance for pipeline engineers. See [docs/PLAN.md](docs/PLAN.md) for the full plan and status.

## Run it

```bash
npm install
```

```bash
npm run dev
```

## Other commands

| Command | What it does |
|---|---|
| `npm run build` | Builds the site into `dist/` and creates the search index |
| `npm run preview` | Serves the built site locally |
| `npm test` | Runs the unit tests for the engineering calculations |

## Disclaimer

Educational use only. Lessons paraphrase and cite industry standards but do not reproduce them. Always work from the current revision of the governing standard and have calculations checked by a qualified engineer.
